# テスト攻略ラボ

テスト勉強の進め方や、問題の解き方、本番での時間の使い方を学べるアプリです。4つの攻略レッスンを読み、学習済みにすると進捗が保存されます。

学習進捗はユーザーのホームディレクトリに `.test_strategy_learning.json` として保存されます。

画面上部では学年・教科・範囲を順番に選び、各段階で一つの選択カードだけが表示されます。「前の選択へ戻る」で前の段階に戻れます。高校1〜3年を選ぶと学年に合わせた教科・範囲の候補が表示されます。教科と範囲を選び「この範囲の問題を出す」と、その範囲の登録済み過去問をテスト形式で解けます。範囲候補は一般的な高校科目・単元をもとにしているため、学校の履修課程と異なる場合は登録済みの範囲も選べます。写真問題を登録すると選択中の学年・範囲に紐づきます。既存の学年情報がない過去問は、どの学年でも候補になります。「すべての教科」を選ぶと学年・教科で絞り込まずに表示します。

学年・教科に応じた標準的な単元候補と、登録済み過去問の範囲から選択できます。候補の範囲に問題がまだない場合は、その範囲を選んで過去問を登録してください。

テスト中に詰まった場合は「答えを見る（詰まったとき）」で模範解答と解き方を確認できます。答えを見た問題は採点せず、「同じ問題をもう一度解く」から再挑戦できます。再挑戦も採点対象外です。

ポイントは同じファイルに保存されます。レッスンを初めて完了すると10ポイント、写真問題に正解すると5ポイント獲得できます。

答え合わせで間違えた写真問題は「苦手問題ノート」に自動で記録され、問題・模範解答・解き方と間違えた回数を確認できます。理解できた問題は「克服した」でノートから外せます。ノートはユーザーのホームディレクトリに `.test_strategy_weak_problems.json` として保存されます。

過去問の写真はローカルのTesseract OCRで読み取ります。読み取り後に模範解答と解き方の解説を登録すると、自分の解答を答え合わせした後に模範解答と解説が表示されます。画像は保存・外部送信されません。日本語OCRを使うには、先にTesseract本体と言語データをインストールしてください。

登録した過去問には教科・単元を付けられます。「保存した過去問を学習する」で、同じテーマや計算・説明・選択などの出題形式を集計します。同じテーマが複数回出ている場合は「過去問から出題を予測」に復習候補を表示します。これは保存した問題の頻度に基づく目安で、実際のテスト問題を保証するものではありません。同じ問題を再登録した場合は重複カウントしません。過去問データはユーザーのホームディレクトリの `.test_strategy_past_questions.json` に保存されます。

頻出テーマには「予想テストに挑戦」ボタンが表示されます。保存済み過去問をテスト形式で1問ずつ解き、答え合わせ・解き方の確認・結果表示ができます。正解ごとに5ポイントを獲得します。

Ubuntu / Debian:

```bash
sudo apt-get install tesseract-ocr tesseract-ocr-jpn
```

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。
